# m3rzo — сайт-визитка + Telegram-панель

Личный сайт веб-разработчика с тремя вкладками (Главная, Обо мне, Сделать заказ), живым чатом и
Telegram-ботом для управления заказами.

## Возможности

- **Сайт:** чёрно-красный переливающийся дизайн, анимированные волны на фоне, буквы заголовка
  реагируют на курсор, пятно-прожектор следует за мышью.
- **Заказы:** клиент заполняет анкету → заявка мгновенно приходит владельцу в Telegram с кнопкой
  «✅ Взяться». Статус заказа (Новый / В работе / Готово / Отклонён) обновляется у клиента на сайте
  в реальном времени.
- **Чат:** клиент пишет через виджет на сайте → владелец получает сообщение в боте и отвечает прямо
  в Telegram → ответ мгновенно появляется на сайте. В боте можно переключаться между клиентами,
  их заказами и чатами с помощью inline-кнопок.

## Запуск

```powershell
npm install
npm run dev     # разработка (авто-перезапуск при изменениях)
npm start       # обычный запуск
```

Сайт откроется на <http://localhost:3000>.

## Настройка (.env)

Скопируйте `.env.example` в `.env`:

```
BOT_TOKEN=токен_бота_от_BotFather
PORT=3000
```

### Как получить токен бота

1. В Telegram откройте **@BotFather** → `/newbot`.
2. Придумайте имя (например, «m3rzo Панель») и username, заканчивающийся на `bot`
   (например, `m3rzo_panel_bot`).
3. BotFather выдаст токен вида `123456789:AAA...` — вставьте его в `.env`.

### Регистрация владельца (важно!)

Владелец определяется по **первому нажатию /start** в боте:

1. Запустите сервер (`npm start`).
2. **Первым делом** откройте своего бота в Telegram и нажмите **/start**.
3. Бот ответит «Ты зарегистрирован как владелец панели» — готово, теперь заявки и сообщения
   клиентов будут приходить вам.

Пока вы не нажали /start, данные клиентов всё равно сохраняются в базу и появятся в меню сразу
после регистрации владельца.

## Панель бота

- **📦 Заказы** — список заявок; внутри заказа кнопки «✅ Взяться», «🏁 Отметить готово»,
  «❌ Отклонить» — клиент видит смену статуса на сайте мгновенно.
- **💬 Чаты** — диалоги с клиентами (счётчики непрочитанных). Откройте чат — и просто пишите
  сообщения в Telegram, они уходят клиенту на сайт. «⏹ Остановить ответы» выключает режим.
- **👥 Клиенты** — карточка клиента: его заказы и последние сообщения.
- **/stop** — выключить режим ответов.

## Технологии

- Node.js 24 (ESM), Express 5, `ws` (WebSocket), grammY (Telegram long polling),
  встроенный `node:sqlite` — без нативных зависимостей, ничего компилировать не нужно.
- Фронтенд: ванильный JS (SPA с hash-роутингом), без сборки.

Данные хранятся в `data/site.db` (SQLite, WAL). Файл создаётся автоматически при первом запуске.

> **Примечание:** папка Desktop может синхронизироваться с OneDrive — SQLite-файлы в
> синхронизируемой папке иногда блокируются. Если заметите ошибки базы, перенесите проект в
> несинхронизируемую папку (например, `C:\Projects\MySite`).

## Публикация в интернет (позже)

Бот работает через long polling — ему публичный адрес не нужен. Но чтобы реальные клиенты могли
зайти на сайт, его нужно опубликовать:

- **Временно, пока ПК включён:** туннель `cloudflared tunnel --url http://localhost:3000`
  или `ngrok http 3000` — получите публичную ссылку.
- **Постоянно:** любой VPS или хостинг с Node.js — скопируйте проект, заполните `.env`,
  `npm install && npm start` (лучше под PM2/системной службой).

## Структура

```
src/            сервер: Express + WS + бот + SQLite
public/         фронтенд: SPA, стили, эффекты
data/site.db    база данных (создаётся автоматически, в git не попадает)
.env            секреты (в git не попадает)
```
